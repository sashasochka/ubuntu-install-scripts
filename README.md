# Retired: Ubuntu install scripts

This 2015 installer collection has been consolidated into
[sashasochka/dotfiles](https://github.com/sashasochka/dotfiles), Sasha's maintained
private Windows/Ubuntu/WSL/VM/cloud configuration repository.

The maintained setup uses one `master` branch, optional roles, read-only plans,
explicit package installation and reversible user configuration. Access to the
private replacement requires authorization from the owner.

Do not run the historical installers on a current machine. They depend on
retired repositories, old Java/Python tooling, privileged global frontend tools
and obsolete bundled packages. Old sudo-ticket and desktop tuning advice is
also retired.

Original files remain recoverable from Git history and the
`legacy-before-consolidation-2026-10-21` tag at
`4f3b72233c2cf2c8e23491da08d7cfc167d1b1b6`. History was not rewritten.

The consolidation audit is in the replacement repository's `docs/AUDIT.md`.
